# SOMNIA AI — Prototype v0.2

هذه نسخة أولية من SOMNIA مع ربط حقيقي بواجهة OpenAI Responses API عبر خادم Node.js.

## ما الذي تغيّر؟
- تحليل السيناريو الذي يكتبه المستخدم باستخدام نموذج ذكاء اصطناعي.
- إنشاء ثلاثة مسارات مشروطة، مع عوامل مؤثرة وأسئلة للتحقق.
- مفتاح API يبقى في الخادم ولا يوضع داخل ملف HTML.
- توضيح صريح أن النتائج احتمالات وليست معرفة مؤكدة بالمستقبل.

## المتطلبات
- Node.js 18 أو أحدث.
- مفتاح API من OpenAI مع تفعيل الفوترة/الرصيد المناسب. اشتراك ChatGPT وحده لا يتضمن تلقائيًا استخدام API.
- اتصال بالإنترنت أثناء التحليل.

## التشغيل على كمبيوتر أو بيئة Node.js
1. فك ضغط الحزمة.
2. افتح الطرفية داخل مجلد المشروع.
3. نفّذ `npm install`.
4. عيّن متغير البيئة `OPENAI_API_KEY` إلى مفتاح API الخاص بك. لا تشاركه مع أحد ولا تضعه في `index.html`.
   - macOS/Linux: `export OPENAI_API_KEY="your_key_here"`
   - Windows PowerShell: `$env:OPENAI_API_KEY="your_key_here"`
5. شغّل `npm start`.
6. افتح `http://localhost:3000`.

يمكن تغيير النموذج عبر متغير `OPENAI_MODEL` إذا لم يكن النموذج الافتراضي متاحًا لحسابك.

## ملاحظة مهمة لمستخدم Android
فتح `index.html` مباشرة من مدير الملفات لن يكفي للذكاء الاصطناعي؛ يجب تشغيل الخادم في مكان يدعم Node.js أو نشره على استضافة آمنة. لا تضع مفتاح API في كود المتصفح أو ترسله إلى أي شخص. يمكنك تطوير الملفات من الهاتف، لكن تشغيل الخادم قد يكون أسهل عبر بيئة Node.js أو استضافة.

## حدود النسخة
هذا نموذج أولي، وليس محركًا علميًا للتنبؤ بالمستقبل. لا يتصل تلقائيًا بمصادر أخبار أو قواعد بيانات علمية؛ التحليل يعتمد على السيناريو والنموذج وما يقدمه المستخدم. قبل إطلاق تجاري، أضف مصادقة، حدود استخدام، حماية من إساءة الاستخدام، سياسة خصوصية، مراقبة للتكلفة، واختبارات.
